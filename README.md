# House Prices — Foundation-First Regression

A Kaggle [House Prices](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques) project built for **learning the fundamentals of regression** with a single algorithm: ordinary least squares (`LinearRegression`).

Deliberately out of scope: ensembles, boosting, bagging, regularization, serving, and tooling beyond a minimal stack.
