# Data

Source: [Kaggle — House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques) (Data tab).

## Setup

This machine has no kaggle CLI or API credentials, so download manually:

1. Join the competition on Kaggle (accept the rules).
2. Download `train.csv` and `test.csv`.
3. Place them here:
   - `data/raw/train.csv`
   - `data/raw/test.csv`

## Layout

- `raw/` — exactly what Kaggle ships. Never edit. Gitignored.
- `processed/` — anything generated by our pipeline. Gitignored.

Both directories are excluded from git (see `.gitignore`); only this README is tracked.
